# Отложенные прототипы

Эти исходники сохранены, чтобы работа не потерялась. Они не входят в актуальные сборки. Новая локальная версия для Apple Silicon находится в [`macos/`](../macos/), а её инструкция — в [`docs/MACOS.md`](../docs/MACOS.md).

- `mac-client/`: отдельный ранний Electron-клиент 1.3; DMG не собран,
  зависимости и упаковщик ещё не зафиксированы. Текущих функций Windows 1.14 здесь нет.
- `network/`: прототип HTTPS-шлюза и настройки частного подключения.
  Сертификаты, ключи, профили, логи и машинный Node.js исключены.
  `setup.ps1` теперь требует явный `-Address`; приватные файлы создаются заново.
  Для `start.ps1` нужен Node.js в `network/runtime/node.exe`.

Сетевой шлюз по текущей конфигурации слушает loopback. Внешнее проксирование
Tailscale здесь не автоматизировано. Не открывайте Ollama напрямую в интернет.
Скрипты не запускаются основным установщиком и требуют отдельной проверки перед
использованием. Задача восстановления сетевого доступа и Mac-приложения отложена.

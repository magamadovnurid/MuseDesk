# Ответы, действия и уточнения

В выпуске 1.24.1 исправлена логика Windows-клиента, которая заставляла модель продолжать работу даже после обычного текстового ответа. Завершение больше не требует обязательного вызова `complete_task`: текст без запросов инструментов принимается как ответ. Инструкции модели отдельно описывают консультации и выполнение действий.

При трёх одинаковых результатах в последних 12 действиях клиент останавливает повторяющиеся действия и запрашивает один итог по имеющимся сведениям. На этом шаге из реального API-запроса исключены инструменты, выключено рассуждение и установлен предел 2048 токена генерации. Если модель снова запрашивает инструмент или не выдаёт текст, клиент сообщает о незавершённой задаче. Такой инструмент не исполняется. Пользователю не нужно писать «попробуй другой способ».

Пустой ответ с одними рассуждениями также получает только одну попытку завершения. Полезная работа не ограничена произвольными шестью шагами: сохранён тест задачи из 20 инструментальных действий с проверкой результата.

`ask_user` предназначен для действительно недостающих сведений. Вопрос должен содержать не более 450 символов и четырёх переносов строки, без блоков кода. Неподходящий вопрос возвращается модели для переформулирования; после двух таких попыток клиент переходит к текстовому итогу. Уже отвеченный вопрос, включая варианты регистра и пунктуации, не открывается повторно. За один запрос допускаются максимум два окна уточнений; дальнейшие ограничения модель объясняет в тексте. Ответ или согласие пользователя не подставляются автоматически.

Сетевые ошибки получают две автоматические повторные попытки, затем показывается сообщение об ошибке без окна «как продолжить». Разрешения на чтение, запись и выполнение команд сохранены без изменений.

На Mac обычное завершение текстом уже поддерживалось; обновлена инструкция о прямых ответах на просьбы дать совет. Windows-механизм `ask_user` и его диалог на Mac отсутствуют.

Проверка использует синтетические ответы модели: прямой ответ с доступными инструментами, повторяющиеся ошибки, отсутствие итогового текста, запрещённый вызов инструмента во время завершения, повторный вопрос и сокращение длинного вопроса. Реальная генерация на рабочей видеокарте при этой проверке не выполнялась. Это улучшение поведения клиента, а не переобучение модели; качество самостоятельного ответа всё ещё зависит от модели.

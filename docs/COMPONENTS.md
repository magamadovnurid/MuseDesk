# Компоненты и установка с чистой системы

## Windows

Поддерживаются Windows 10 x64 версии 2004+ и Windows 11 x64. Эти системы уже содержат .NET Framework 4.8 или новее, поэтому графический установщик открывается без отдельной установки среды. Повреждённая или вручную удалённая системная среда требует восстановления Windows.

Мастер проверяет установленный Framework. На Windows 10 21H2+ и Windows 11 при отсутствии 4.8.1 автоматически скачивает актуальный пакет ветки 4.8.1 по официальной ссылке Microsoft, проверяет действительность Authenticode и издателя Microsoft Corporation и запускает установку. Более новые установленные версии сохраняются. На Windows 10 2004/20H2/21H1 используется совместимая встроенная 4.8.

Для изменения системного компонента Windows может запросить права администратора. Установка выполняется с `/norestart`: при необходимости перезагрузки мастер сообщает об этом и не выдаёт незавершённую установку за готовую. После перезагрузки пользователь запускает тот же EXE повторно.

Visual C++ Runtime DLL входят в проверенный архив Ollama вместе с GPU-библиотеками. Отдельно устанавливать Visual Studio, CUDA Toolkit, Python, Node.js, .NET SDK или глобальный Ollama не требуется. Для NVIDIA необходим совместимый установленный драйвер; смену драйвера и обновление самой ОС установщик не выполняет.

## Mac

DMG/ZIP содержит приложение вместе с Electron и его средой. Не нужны Homebrew, Xcode, Node.js, Python или .NET. При первом запуске мастер проверяет именно этот Mac: Apple Silicon, macOS 14+, объединённую память и место на диске. Приватный движок и подходящие веса Glimmer скачиваются автоматически после запуска настройки. Metal предоставляется macOS.

Для Glimmer требуется от 32 ГБ объединённой памяти; от 64 ГБ выбирается более точный кодировщик изображений F16. Модель не скачивается автоматически на неподходящем оборудовании.

## Какие версии устанавливаются

Мастер обеих платформ запрашивает последний стабильный выпуск `ollama/ollama` на GitHub и сравнивает его с проверенным каталогом приложения. На момент выпуска 1.24.0 это **0.33.3**, текущая стабильная версия. Совпадение имени файла, размера и SHA-256 проверяется по метаданным выпуска; загруженные байты отдельно проверяются по закреплённому SHA-256.

Новый непроверенный движок не подменяет совместимый автоматически: мастер сообщает о новом выпуске и использует проверенную версию. Обновление каталога распространяется вместе со следующим проверенным выпуском Muse Desk. Это сознательная граница автоматизации: проверка «latest» не является доказательством совместимости с форматом Glimmer. При недоступности API остаётся проверенный каталог; для самих загрузок интернет всё равно необходим.

Скачивание поддерживает продолжение после обрыва. Повреждённый кеш удаляется только после несовпадения размера/хеша и скачивается заново; ошибка контрольной суммы частичного файла позволяет повторить загрузку кнопкой в мастере. Веса закреплены на конкретной ревизии Hugging Face.

## Границы проверки выпуска

Автоматизация проверяет Windows-приложение, отдельную установку без модели, политики системных компонентов, восстановление загрузок, Mac-интерфейс, фактический движок Apple Silicon без моделей и собранный `.app`. Установка .NET с повышением прав проверяется тестами решений и результатов, но не выполняется на рабочем компьютере разработчика. Полная аппаратная приёмка генерации Glimmer и проверка всех вариантов чистой ОС ещё нужны.

Пока отсутствуют сертификаты Windows Authenticode и Apple Developer ID/нотариализация. Поэтому SmartScreen/Gatekeeper могут потребовать дополнительное подтверждение. Полностью беспрепятственный первый запуск нельзя обещать до выпуска подписанных пакетов.

# Muse Desk 1.22.0 — Windows installer preview

Первый отдельный графический установщик Muse Desk: проверка оборудования, подбор профиля Glimmer, загрузка закреплённых компонентов с Hugging Face и GitHub, SHA-256, возобновление загрузки и установка для текущего пользователя.

## Скачать и установить

Скачайте **MuseDesk-Setup.exe** из вложений выпуска и запустите. Git и Node.js не нужны. Контрольная сумма опубликована в **SHA256.txt**.

Для автоматической установки Glimmer нужны Windows x64 с .NET 4.8, NVIDIA от 24 ГБ VRAM с Compute Capability 7.5+, 32 ГБ RAM и 40 ГБ свободного места. Загрузка составляет около 20–22 ГБ. Для неподходящей GPU доступна установка только приложения. Подробности: [руководство](https://github.com/magamadovnurid/MuseDesk/blob/main/docs/INSTALLATION.md).

## Изменения приложения

- Проекты из папок, вложенные чаты, перенос чатов и единые подтверждения удаления.
- Обновлённый светлый интерфейс, собственные значки, меню и кнопки управления окном.
- Последовательная загрузка моделей, ожидание подтверждённой готовности и блокировка ввода до неё.
- Время отправки и завершения ответа, адаптивное поле ввода, тонкая прокрутка и журнал действий.
- Новые установки начинают с контекста 8192 и выключенных инструментов.

## Статус проверки

Пройдены изолированные проверки приложения и установки без модели, проверки профилей, хешей и защиты путей архива. Настоящий архив Ollama скачан и проверен; прерывание и возобновление загрузки модели проверены отдельно.

**Это предварительный выпуск.** Полная загрузка весов и генерация на чистом компьютере получателя ещё не проверены. Проверка объёма памяти не гарантирует стабильность GPU. EXE пока не подписан Authenticode; Windows может показать предупреждение SmartScreen. Автообновление и отдельный деинсталлятор ещё не реализованы.

# Проверка перед публичной публикацией

7 сентября 2026 года проверены все 14 исходных коммитов сканером Gitleaks 8.30.1 с редактированием значений в отчёте. Действующие ключи, токены и пароли сканером не обнаружены. Локальный расширенный проход дал два срабатывания в примерах документации самого сканера; эти файлы не отслеживаются Git и не входят в пакеты.

В метаданных исходного коммита обнаружены персональное имя и email. Они заменены нейтральными данными проекта; история ветки и релизных тегов пересоздана без изменения исходных деревьев файлов. Уже опубликованные старые объекты могут оставаться в кешах GitHub, старых ссылках и чужих клонах. Для удаления серверных кешей требуется обращение владельца в GitHub Support. Это не утечка учётного токена и не основание придумывать необходимость смены пароля.

Скриншоты документации проверены визуально: они показывают демонстрационные проекты, диалоги и оборудование. История реальных чатов, подключения, вложения, локальные логи, модели и сертификаты исключены из Git и из состава установочных пакетов.

Добавлены автоматические проверки всей доступной истории: Gitleaks, запрет приватных файлов в индексе и проверка email авторов/коммитеров. Публикация новых пакетов зависит от успешного прохождения этого этапа. Проверка сканером снижает риск, но не доказывает отсутствие любых возможных персональных данных.

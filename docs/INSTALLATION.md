# Установка Muse Desk на Windows

Выпуски включают **Windows EXE/ZIP, macOS DMG/ZIP и Ubuntu DEB**. Это руководство описывает Windows. Для других платформ: [установка macOS](MACOS.md) · [установка Ubuntu](UBUNTU.md).

## Что передать другому человеку

Передайте **MuseDesk-Setup.exe** из папки «Muse Desk Install» либо ссылку на GitHub Release. `SHA256.txt` позволяет сравнить контрольную сумму. EXE содержит приложение и инструкции установки, но не многогигабайтные веса. Это онлайн-установщик. Нужны Windows 10 2004+ / Windows 11 x64, .NET Framework 4.8 и стандартный `curl.exe` Windows.

Установщик пока не подписан сертификатом издателя: Windows может показать предупреждение SmartScreen. Проверяйте источник файла и SHA-256. Программа не запрашивает обход защит Windows и не устанавливает драйверы.

## Пошагово

1. Запустите установщик обычным пользователем. По умолчанию используется `%LOCALAPPDATA%\Programs\Muse Desk`.
2. Дождитесь определения оборудования. При необходимости выберите другую **пустую** папку на диске с достаточным свободным местом. Рабочий пакет разработчика не используется как источник данных и не изменяется.
3. Проверьте рекомендуемый профиль. При подходящем оборудовании модель выбрана автоматически; можно выбрать «только приложение».
4. Нажмите «Установить». Идут распаковка приложения, загрузка движка, загрузка текстовых весов и кодировщика изображений, проверка хешей, регистрация модели и создание ярлыков.
5. Нажмите «Открыть Muse Desk». При запуске модели дождитесь «Готово». Если модель ещё не готова, ввод заблокирован.

Движок и веса берутся с закреплённых HTTPS-адресов GitHub/Hugging Face. Для обычной работы с установленной моделью VPN не нужен. Загрузка зависит от доступности этих сайтов в вашей сети; установщик не является средством обхода сетевых ограничений.

## Объём и оборудование

- Движок: Ollama 0.33.3, архив около 1.47 ГБ, плюс место на распаковку.
- Текстовые веса Glimmer Heretic Q4_K_M: около 16.94 ГБ.
- Кодировщик изображений: около 2.05 ГБ (Q8_0) или 3.85 ГБ (F16).
- Запас диска для автоматической установки: 40 ГиБ свободно до начала. Архив движка сохраняется для повторной установки.
- Порог памяти: 32 ГБ RAM (31 ГиБ доступного аппаратного объёма с учётом резервирования), 24 ГБ VRAM (≥23000 МиБ по `nvidia-smi`); Compute Capability ≥7.5. Для F16-кодировщика — ≥31000 МиБ VRAM.
- AMD, Intel, ARM64 и CPU-only пока не входят в матрицу автоматической установки Glimmer. Неподтверждённая совместимость не подменяется приблизительным значением WMI `AdapterRAM`.

Источник сборки: [mradermacher/Muse-Glimmer-30B-heretic-GGUF](https://huggingface.co/mradermacher/Muse-Glimmer-30B-heretic-GGUF), ревизия указана в `installer/catalog.json`. Это сторонняя Heretic-сборка; она не тождественна официальным весам Meta и не тождественна старому пакету Ollama разработчика побайтно. Локальный тег совместимости остаётся `acc100/muse-glimmer-heretic:latest`, но файлы и происхождение записаны отдельно в журнале установки и каталоге.

## Если загрузка прервалась

Нажмите «Остановить» и дождитесь завершения текущей операции. Проверка SHA-256 может занять несколько минут; на этом этапе закрытие ждёт окончания проверки. Повторите установку в ту же папку: файлы `.part` докачиваются через HTTP Range, проверенные файлы не скачиваются повторно.

Если сервер не поддержал возобновление, вернул ошибку или SHA-256 не совпал, установка не объявляется успешной. Путь проблемного файла будет показан в сообщении. Переместите этот файл в сторону и повторите установку. Существующие повреждённые файлы установщик молча не заменяет.

При ошибке сохранённые компоненты остаются в папке для повторной попытки; транзакционного отката всей установки пока нет. Перед обновлением закрывайте работающий Muse Desk. Не выбирайте папку действующей переносной копии: непустая директория без маркера установщика отклоняется.

## Где находятся данные

| Путь | Содержимое |
|---|---|
| `<установка>\release` | Приложение, конфигурация .NET, значок |
| `<установка>\runtime\ollama` | Отдельный движок и его зависимости |
| `<установка>\data\models` | Проверенные blobs и манифест модели |
| `<установка>\installation.log` | Журнал этапов установки |
| `<установка>\musedesk-install.json` | Статус установки и ревизия модели |
| `%APPDATA%\MuseDesk` | История и пользовательские настройки приложения |
| `%LOCALAPPDATA%\MuseDeskInstaller` | Временные рабочие каталоги установщика |

Ярлыки создаются на рабочем столе и в пользовательском меню «Пуск». Права администратора по умолчанию не нужны. Сетевые порты наружу и правила брандмауэра не создаются. Модель во время инсталляции не загружается в VRAM.

## Удаление

В этой предварительной версии отдельного деинсталлятора нет. Закройте приложение и его локальный движок, удалите папку установки и ярлыки. История в `%APPDATA%\MuseDesk` сохраняется отдельно; удаляйте её только если хотите удалить свои диалоги. Рабочие папки проектов расположены там, где вы их выбрали, и не удаляются вместе с программой.

## Диагностика

При обращении приложите текст ошибки, версию Windows, название GPU, объём RAM/VRAM и `installation.log`. Не публикуйте историю чатов или файлы проектов. Успешная проверка объёма памяти не диагностирует блок питания, драйверы, перегрев и аппаратные перезапуски. Qwen не включена в автоматический установщик: её живые тесты на машине разработчика сопровождались hard reset, точная аппаратная причина не установлена.

Подробная схема системных компонентов, обновлений и восстановления загрузок: [Компоненты](COMPONENTS.md).

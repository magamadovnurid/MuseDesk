# Muse Desk для Ubuntu

Ubuntu-версия использует общий интерфейс и логику клиента macOS: проекты из папок, вложенные чаты, потоковые ответы и рассуждения, Markdown, код, вложения текста и изображений, подтверждаемые инструменты, журнал действий, экспорт, даты сообщений, результаты и источники. Дизайн, навигатор тем, прокрутка и состояние готовности модели обновляются в одном исходном коде для обеих платформ.

## Установка

1. Скачайте **MuseDesk-1.25.0-Ubuntu-amd64.deb** из [Releases](https://github.com/magamadovnurid/MuseDesk/releases/latest).
2. Откройте пакет в системном установщике программ. Если файловый менеджер открывает архив, используйте терминал в папке скачивания:

   ```bash
   sudo apt install ./MuseDesk-1.25.0-Ubuntu-amd64.deb
   ```

3. Запустите **Muse Desk** из меню приложений. Мастер проверит именно этот компьютер и объяснит, подходит ли он для Glimmer.
4. На подходящем компьютере нажмите **Установить Glimmer**. Приложение скачает проверенный Linux-движок Ollama и веса модели, проверит SHA-256 и зарегистрирует модель. Загрузка может быть остановлена и продолжена.
5. Дождитесь **Готово**: ввод включается после проверки единственной выбранной модели в движке.

Node.js, Python, .NET и отдельная установка Ollama не нужны. DEB содержит Electron и через APT устанавливает GTK, библиотеки интерфейса, curl, zstd и espeak-ng. Системные пакеты устанавливаются штатным механизмом Ubuntu; встроенный мастер настройки модели оформлен в стиле Muse Desk. Нужен доступ к репозиториям Ubuntu, GitHub и Hugging Face.

## Совместимость

- Приложение: Ubuntu 22.04 или новее, x86-64 (amd64), графическая сессия.
- Автоматическая установка Glimmer: 32 ГБ RAM (ядру доступно не менее 30 ГиБ), одна NVIDIA с 24 ГБ VRAM (не менее 23 ГиБ), Compute Capability 7.0+, драйвер NVIDIA 550+, 40 ГиБ места.
- Две видеокарты по 12 ГБ не считаются одной картой на 24 ГБ. Выбирается одна подходящая GPU, память карт не суммируется.
- Профиль: Glimmer Q4_K_M с Q8-кодировщиком. Модель — около 19 ГБ, архив Linux-движка — дополнительно около 1,4 ГБ.
- AMD, Intel, ARM64 и CPU-only пока не входят в автоматическую установку Glimmer. На неподходящей GPU скачивание модели блокируется, существующие чаты доступны.

Драйвер GPU не заменяется приложением: установите рекомендованный драйвер в **Программы и обновления → Дополнительные драйверы**. Это системная операция, которая может требовать перезагрузки или настройки Secure Boot. Требования движка сверены с [документацией Ollama](https://docs.ollama.com/gpu); политика первого Ubuntu-выпуска намеренно уже общего списка поддерживаемых Ollama GPU.

Проверка оборудования не гарантирует скорость или устойчивость генерации на каждом компьютере. Аппаратный прогон Glimmer на Ubuntu с реальной NVIDIA пока не выполнен. CI проверяет настоящий Linux-движок без загрузки весов, установку DEB и интерфейс собранного приложения.

## Данные и управление

История: `~/.config/Muse Desk/history.json`. Модели, движок и журналы: `~/.config/Muse Desk/local/`. Диагностика проверки оборудования записывается в `hardware-check.json`; пункт **Справка → Журналы** открывает папку. Удаление проекта из интерфейса удаляет его чаты из Muse Desk, но сохраняет файлы проекта на диске.

Команды инструментов выполняются через Bash в папке проекта с подтверждением пользователя. Озвучивание использует локальный espeak-ng; качество голоса зависит от установленных голосов. Движок запускается от обычного пользователя, слушает только localhost:11436 и ограничен одной загруженной моделью и одним параллельным запросом.

## Разработка

Общий клиент остаётся в каталоге `macos/` для совместимости существующих путей сборки; Ubuntu не является отдельной копией интерфейса.

```bash
cd macos
pnpm install --frozen-lockfile --ignore-scripts
node node_modules/electron/install.js
pnpm test
pnpm build:linux
```

DEB появляется в `dist-linux/`. В CI установка и UI smoke выполняются в Ubuntu; релиз публикуется только после успешных проверок всех трёх платформ и аудита приватности.

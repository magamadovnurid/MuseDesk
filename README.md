# Muse Desk 1.14 — Windows x64

Нативное Windows-приложение для локальной Muse Glimmer Heretic: WinForms,
C# / .NET Framework 4.8, без Electron в основной Windows-версии.
Сохранены исходники действующей версии, векторные ресурсы, тесты и сборщик.

## Восстановить на другом компьютере

Нужны Windows x64, .NET Framework 4.8, Windows PowerShell 5.1 и Git.
Для модели требуется примерно 20.8 ГБ на диске плюс место для движка, архива
и временной распаковки. Эта конфигурация использовалась с RTX 3090 / 24 ГБ VRAM;
на меньшем GPU возможна выгрузка в RAM и существенное снижение скорости.
Автоподбора модели по железу пока нет.

В PowerShell (права администратора для сборки не нужны):

```powershell
git clone https://github.com/magamadovnurid/MuseDesk.git
cd MuseDesk
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\setup-windows.ps1
.\release\MuseDesk.exe
```

`setup-windows.ps1` собирает EXE, скачивает официальный архив Ollama 0.33.3,
проверяет SHA-256, распаковывает отдельный движок и скачивает модель.
Ожидаемые версии и контрольные суммы записаны в `runtime.lock.json`.
Параметр `-SkipModel` пропускает загрузку модели, но не движка.
Загрузка может быть долгой; повторный запуск использует сохранённые blobs.
Скрипт не открывает порты в брандмауэре, не включает сетевой доступ и не меняет
системные службы Ollama. Временный сервер загрузки запускается на loopback.

Тег модели `latest` у стороннего издателя может измениться. Если SHA-256
манифеста отличается, установщик остановится с понятной ошибкой — это защита
от незаметной замены модели. Доступность старых весов у издателя не гарантируется.
Для независимого офлайн-восстановления храните отдельно резервную копию
`runtime/` и `data/models/`; GitHub не является резервной копией весов.

## Только собрать / проверить исходники

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\build-windows.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\test-windows.ps1
```

Ни модель, ни интернет, ни Node.js для этих команд не нужны. Сборщик использует
64-разрядный `csc.exe`, поставляемый с .NET Framework. Результат: `release/MuseDesk.exe`,
конфигурация и значок. В Windows должны присутствовать `System.Speech` и WinForms.
Обычные тесты изолированы от личной истории и не обращаются к живой модели.
Тесты `-Live` запускайте отдельно, только когда локальный движок настроен.
Отчёты и синтетические превью пишутся в `test-output/`.

GitHub Actions содержит Windows-сборку, тесты и выгрузку EXE как артефакта
`MuseDesk-Windows-x64`. Это не подписанный установочный пакет; SmartScreen может
показывать предупреждение неизвестного издателя.

## Состав репозитория

| Путь | Назначение |
| --- | --- |
| `windows-native/` | Исходники приложения, тесты и ресурсы |
| `scripts/` | Сборка, установка движка, проверка и регенерация иконок |
| `runtime.lock.json` | Версия движка и отпечаток модели |
| `.github/workflows/` | Автоматическая Windows-сборка и тесты |
| `experimental/` | Отложенные прототипы Mac-клиента и сетевого шлюза |

При запуске EXE из `release/` приложение ищет движок в `runtime/ollama/`,
веса — в `data/models/`, сервер — на `127.0.0.1:11436`.
Не переносите один EXE, ожидая, что вместе с ним перенесётся модель.
Если используется уже установленный Ollama из PATH, приложение всё равно
создаёт отдельный сервер с собственной директорией моделей.

## Возможности и ограничения

- Чаты и проекты, поиск, результаты работы, потоковый ответ и копирование значком.
- Вложения: текст, исходники, DOCX/XLSX/PPTX, изображения и снимок экрана.
- Инструменты: файлы, команды, веб-запросы; ход работы, уточнения и итог с файлами.
- Память проекта, поиск по сохранённой истории, сокращение контекста и повтор
  запроса при переполнении. Полная история остаётся на диске, но не помещается
  целиком в каждый запрос — окно модели конечно.
- Права на каждый чат: полный доступ, подтверждения, ограниченный доступ
  к выбранной папке. Ограниченный режим — политика клиента, не OS-песочница;
  полный доступ не выдаёт права администратора Windows.
- Индикатор активности чата; одновременно выполняется одна генерация.
- Диктовка и озвучивание через компоненты Windows; это не нативный аудиорежим модели.

`Enter` — отправка, `Shift+Enter` — перенос строки, `Esc` — остановка,
`Ctrl+N` — новый чат, `Ctrl+K` — поиск, `Ctrl+,` — настройки.

История и настройки находятся в `%APPDATA%\MuseDesk`, а не в Git.
Они не шифруются приложением. Не публикуйте эту папку, сертификаты, `.env`,
файлы подключения и вложения. Остановка задачи не отменяет выполненные изменения
и не гарантирует завершение всех дочерних процессов разрешённой команды.

## Редактирование иконок

Готовый `windows-native/assets/icons/icons.zip` уже включён в исходники.
Для регенерации установите Node.js 22+ и выполните:

```powershell
npm ci
npm run build:icons
```

Зависимости закреплены в `package-lock.json`. Конвертер читает только SVG из
репозитория; установка Codex не требуется. Происхождение сторонних ресурсов
и нерешённый вопрос лицензии части иконок описаны в
[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md). Сохранение существующего UI
не означает, что для этих ресурсов автоматически предоставлена лицензия.

Готового DMG и универсального установщика с подбором модели пока нет.
Прототипы сохранены в `experimental/`, но не объявляются готовым продуктом.
